# 🛒 かいものにいこう！ - とくべつしえん がくしゅうアプリ

特別支援学校（小学部・中学部・高等部）の生活単元学習「買い物に行こう」のために開発された、iPad最適化Webアプリです。

## 🌟 アプリのとくちょう
- **すべて ひらがな ひょうき**：難しい漢字やカタカナをなくし、児童がひとりで読みやすい設計。
- **Googleがぞうけんさく と れんどう**：お菓子ボタンを押すとGoogle検索が開き、自由にお気に入りのパッケージ画像を探せます。
- **かんたん スクショきりとり機能**：iPadで撮ったスクショから、お菓子の部分だけを四角い枠でかんたんに切り抜けます。
- **じどう けいさん ＆ じょうけんチェック**：
  - ① おかしは ２こまで
  - ② 200円まで
  - 条件を自動で判定し、リアルタイムに「あと〇〇えん かえるよ」とお知らせします。
- **A4いんさつ プリントたいおう**：完成すると、実際の学習プリントと同じデザインのきれいなワークシート画像（PNG）が自動生成され、保存・印刷できます。

## 📁 ファイル構成
- `index.html` : アプリの画面構成
- `style.css` : iPad最適化デザイン
- `snack-data.js` : ひらがなお菓子データベース
- `app.js` : アプリ動作プログラム（効果音、トリミング、Canvas合成）
